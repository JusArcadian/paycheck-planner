## The one command to remember
```bash
python menu.py
```
Run it in PyCharm's Terminal, inside the BudgetTool folder. It shows a numbered menu: backup, update inflation, build, build + push, practice push, listing copy.

## Keyboard shortcuts

### Windows
| Keys | Does |
|---|---|
| **Win + Shift + S** | Screenshot part of the screen (then paste it to Claude with Ctrl+V) |
| **Win + V** | Clipboard history: paste something you copied earlier |
| **Win + E** | Open File Explorer |
| **Alt + Tab** | Switch windows |
| **F2** | Rename the selected file |
| **Ctrl + Shift + Esc** | Task Manager (a frozen app) |

Tip: in File Explorer, right-click your **Portfolio** folder → **Pin to Quick access**, so it's always one click away.

### PyCharm
| Keys | Does |
|---|---|
| **Ctrl + Esc** | Open Claude Code |
| **Alt + F12** | Open/close the Terminal |
| **Shift, Shift** (tap twice) | Search everything: files, settings, actions |
| **Ctrl + Shift + F** | Find text in every file |
| **Ctrl + Shift + F10** | Run the file you're looking at |
| **Ctrl + K** | Git: commit (save a checkpoint) |
| **Ctrl + Shift + K** | Git: push to GitHub |
| **Ctrl + /** | Turn a line into a comment (or back) |
| **Ctrl + Z / Ctrl + Shift + Z** | Undo / redo |
| **↑** in the Terminal | Bring back the last command (no retyping!) |

### Claude Code (in PyCharm)
| Keys / command | Does |
|---|---|
| **Shift + Tab** | Switch modes (keep "ask before edits" while learning) |
| **Esc** | Stop Claude mid-task |
| **@** then a file name | Point Claude at a specific file |
| **/remote-control** | Continue this session from your phone (QR code) |

### Google Sheets and Excel
| Keys | Does |
|---|---|
| **Ctrl + ;** | Type today's date (perfect for the Spending tab) |
| **Ctrl + Shift + ;** | Type the current time |
| **Ctrl + Z** | Undo |
| **Ctrl + /** | (Google Sheets) show every shortcut |
| **Ctrl + Alt + M** | (Google Sheets) add a comment |
| **File → Version history** | (Google Sheets) go back to any older version |
